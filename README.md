# Computer Vision Internship Assessment

This repository contains the solutions for the Computer Vision Internship Assessment tasks.

## Tasks Completed

1.  **Task 1: Basic Image Manipulation:** A Python script (`task1_image_manipulation.py`) that loads an image and applies grayscale conversion, Gaussian blur, and Canny edge detection.
2.  **Task 2: Mini Project - Color Detector:** A Python script (`task2_color_detector.py`) that uses the webcam to detect the BGR color value and approximate color name of the pixel clicked by the user.
3.  **Task 3: Summary Report:** A 1-page PDF report (`task3_documentation.pdf`)

# How to Run
## Task 1: Image Manipulation
1.**Place an input image (e.g., input_image.jpg) in the root directory or modify the INPUT_IMAGE_PATH variable in the script.**

2.**Run the script:
    python task1_image_manipulation.py**
    
3.**Processed images will be saved in the output_task1/ directory.**

## Task 2: Color Detector
1.**Ensure the colors.csv file is in the root directory, or provide the path using the -c argument. A sample colors.csv is included. You can find more comprehensive ones online.**

2.**Run the script:
python task2_color_detector.py**

3.**A webcam feed window will open. Click on the window to see the BGR values and approximate color name.**

4.**Press 'q' to quit**
